Agrupaciones y dúos

Una agrupación = un proyecto = un cupo. Cada integrante autoriza por sí mismo con el enlace de su grupo. Cuando dos agrupaciones tienen un nombre equivalente, tú decides si son el mismo proyecto: el sistema no fusiona nada.

Paso 1 · Revalidar todo

Vuelve a aplicar edad, residencia, formato, duplicados y agrupaciones repetidas. Respeta tus decisiones manuales y nunca quita códigos ya emitidos.

Paso 2 · Emitir B-001 … B-100

Asigna código, bloque y horario a los APTO, en orden de inscripción. Una agrupación recibe un solo código. Es idempotente: nunca reasigna ni reutiliza un código. Los REVISIÓN no reciben código hasta que decidas.

Revisa antes de emitir Resuelve primero las agrupaciones repetidas y las inscripciones en revisión.

Ocupación por bloque

Solicitudes de cambio

El participante nunca elige la hora: la decides tú, y solo en un bloque con cupo libre.

Pistas

Estados: PISTA PENDIENTE → RECIBIDA → VALIDADA (o CON PROBLEMA). Los archivos quedan en Audio/B-XXX/ con el nombre B-XXX_ARTISTA_CANCION. Descarga la carpeta completa antes del evento para el técnico (copia offline) y pide a cada participante su USB de respaldo.

Subir una pista recibida por WhatsApp

Generar mensajes

El sistema prepara el texto exacto. El envío por WhatsApp lo hace una persona desde el número oficial con el enlace generado (enviar automáticamente exige la API paga de WhatsApp Business). Solo se genera enlace de WhatsApp para quien autorizó ese canal.

Cuota de correo Una cuenta Gmail envía ~100 correos al día. WhatsApp es el canal principal.

Contactos para la lista de difusión

Descarga un archivo de contactos (.vcf) con quienes autorizaron WhatsApp, para importarlo en el teléfono del número oficial y crear la lista de difusión o el grupo. La difusión solo llega a quien también guardó el número oficial.

Videos

Comprueba que los enlaces se puedan abrir sin iniciar sesión (corre solo cada hora; aquí lo fuerzas). Instagram y TikTok no se pueden verificar automáticamente: quedan como NO VERIFICABLE para revisión manual.

Respaldos

Cada respaldo crea un XLSX (con las agrupaciones colapsables) y un JSON restaurable en Drive. Hay uno automático cada noche. Haz uno con etiqueta en cada hito.

Vistas y cierre

AGENDA, CHECK-IN, AGRUPACIONES, PISTAS, RESULTADOS y DASHBOARD se reconstruyen desde REGISTRO.

Estado del sistema

Entorno, marca de la hoja, esquema, formularios, datos legales y ausencia de datos de prueba.

Accesos del equipo

Cada persona recibe su propio enlace. No se comparten entre roles.
