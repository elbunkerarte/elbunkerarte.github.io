# EL BÚNKER — Manual operativo en 1 página

Detalle completo: [OPERACION_ECOSISTEMA_FINAL.md](OPERACION_ECOSISTEMA_FINAL.md). Los nombres entre **negritas**
son los de la pantalla. Cada persona usa **solo su enlace personal**; no se comparte.

## Qué abrir primero
- **Coordinación / logística:** tu enlace del panel (`…/exec?p=admin&t=…`) → pestaña **Inscritos** (métrica **Por revisar**).
- **Dirección:** tu enlace del dashboard (`…/exec?p=dashboard&t=…`).
- **Check-in, stage manager, técnico de audio:** tu enlace de check-in (`…/exec?p=checkin&t=…`).
- **Jurados:** tu enlace de jurado (`…/exec?p=jurado&t=…`).
- Participantes: `https://elbunkerarte.github.io/` → **Inscríbete** o «Mi inscripción».

## Qué revisar cada día (logística)
- [ ] **Aptitud y códigos → Aplicar verificación y enviar resultados**.
- [ ] **Inscritos**, filtro «Por revisar»: decidir cada EN REVISIÓN en **Decisión** (siempre con motivo).
- [ ] **Agrupaciones**: resolver «Posible agrupación repetida» (**Es el mismo proyecto** / **Son proyectos distintos**).
- [ ] **Cambios de horario**: **Aprobar** (con **Nuevo bloque**) o **Rechazar** cada solicitud.
- [ ] Desde el 16-oct: **Bolsa y reemplazos** → cupos OFRECIDO / LIBERADO / VACANTE SIN REEMPLAZO e **Historial de ofertas**.
- [ ] **Comunicación → Registro de correos** → «Fallidos» → **Reintentar fallidos**.
- [ ] En cada hito: **Respaldo y sistema → Respaldo completo** con su etiqueta.
- [ ] Nunca editar a mano las hojas de la base, ni `CONFIG`, ni `PARAMETROS_RUBRICA`. El Excel es solo una foto.

## Qué hacer ante una vacante
1. Si la persona avisa por teléfono o WhatsApp: **Bolsa y reemplazos → Retirar a un participante** → Código + Motivo → **Retirar y ofrecer el cupo** (el 22-oct, marcar **Es un retiro de la confirmación final (22 de octubre)**). No se puede deshacer.
2. El sistema ofrece el cupo a **un suplente a la vez** (24 h para aceptar en Mi inscripción). Si rechaza o no responde, pasa solo al siguiente.
3. Después del **22-oct 12:00 m.** ya no hay reemplazos: el cupo queda **VACANTE SIN REEMPLAZO**. Antes de esa hora, si hay nuevos aptos: **Ofrecer al siguiente**.
4. Nunca escribir un nombre a mano en la hoja para llenar el cupo.

## Cómo cerrar la lista (jueves 22-oct)
1. Temprano: **Comunicación** → plantilla «Confirmación final de asistencia (22-oct)» → **Enviar por correo**.
2. Resolver todos los **Cambios de horario** pendientes (después de consolidar ya no se pueden resolver).
3. Después de las **8:00 p. m.**: **Bolsa y reemplazos → Vista previa y conteos**. No debe haber «Códigos con dos titulares» ni «Hay cambios pendientes».
4. **CONSOLIDAR LISTA OFICIAL DEL EVENTO** → escribir **CONSOLIDAR**. Queda la foto `ROSTER_FINAL_2026-10-22` y se bloquean los cambios.

## Día del evento (viernes 23-oct, 3:00–9:00 p. m., C.C. Mayorca · Etapa 1)
- Check-in: **Buscar participante** → validar documento físico → **Confirmar CHECK-IN** → **Pasar a PRECOLA** → **Sube a escena (EN AUDICIÓN)** → **Audición REALIZADA (salida)**. Más de 5 min tarde: **Pasar a CONTINGENCIA**. Si falta una firma: **Abrir constancia imprimible (firmas en papel)**.
- 8:30 p. m.: **Contingencia → Calcular plan ahora**. 9:00 p. m.: logística pulsa **Cerrar jornada**.

## Cómo iniciar jurados
1. Cada jurado abre **su** enlace (`jurado-1`, `jurado-2`, `jurado-3`) y lee **Cómo calificar (rúbrica oficial)**.
2. Solo se califica cuando la audición está **REALIZADA** (máximo 3 minutos por audición).
3. 7 categorías de 1 a 5 → **Guardar borrador** → **ENVIAR Y BLOQUEAR EVALUACIÓN**. Una evaluación enviada solo la reabre dirección.
4. Si un enlace no abre: admin genera uno nuevo en **Accesos del equipo** (nota «jurado 1/2/3»); el anterior deja de servir.

## Cómo consultar resultados (dirección)
1. Dashboard → **Resultado consolidado (privado)** → **Calcular resultados**. Puntaje = promedio de los 3 jurados.
2. **Top 10** = seleccionados públicos. **Top 20** = privado: nunca se publica ni se comunica.
3. Empate en el corte 10 o 20 que no resolvió Presencia escénica + Factor arena → **Acta de desempate** → **Registrar acta**.
4. Descalificaciones: **Ver reportes** → **Validar** / **Descartar**. Error de un jurado: **Reabrir evaluación**.
5. **Cerrar resultados** → escribir **CERRAR**. Luego logística envía «Resultado final (tras cerrar resultados)» desde **Comunicación**.
